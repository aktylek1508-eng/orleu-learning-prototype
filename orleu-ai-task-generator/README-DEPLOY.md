# Орлеу оқу прототипі — файлдан тапсырма генераторы

## Функция

Мұғалім «Задания» бөлімінде «Создать задание по файлу» батырмасын басып, фото/скан, PDF, Word, PowerPoint, Excel немесе мәтіндік файлдан қазақша тест сұрақтарын жасата алады. Құрастырылған сұрақтар қолданыстағы редакторға енгізіледі: мұғалім оларды тексеріп, жауаптарын өңдеп, «Сохранить задание» арқылы тағайындайды.

Қолдау көрсетілетін кеңейтімдер: PNG, JPG/JPEG, WEBP, GIF, PDF, DOC/DOCX, RTF, ODT, PPT/PPTX, XLS/XLSX, CSV, TSV, TXT, MD, JSON. Файлдың шегі — 3 МБ.

## Vercel арқылы жариялау

1. Осы қалтадағы `outputs` және `api` қалталарын, `vercel.json` файлын бір Vercel жобасының түбіріне жүктеңіз.
2. Vercel → Project → Settings → Environment Variables бетінде `OPENAI_API_KEY` атты айнымалы жасап, OpenAI API кілтін **мәні** ретінде енгізіңіз. Кілтті HTML ішіне немесе GitHub-қа салмаңыз.
3. Жаңа deployment жасаңыз.
4. Қажет болса, модельді `OPENAI_MODEL` айнымалысымен ауыстыруға болады; әдепкі мәні `gpt-5.4-mini`.

`file://` арқылы ашылған HTML-де API функциясы жұмыс істемейді; сайт Vercel сияқты serverless функцияларды іске қосатын хостингте жариялануы тиіс.

## Файлдар

- `outputs/index.html` — екі тілдегі интерфейс және генератор.
- `api/generate-task.js` — файлды серверден өңдейтін API маршруты.
- `vercel.json` — `outputs` статикалық бумасын және API функциясын жариялау баптауы.

## Прототипийн шектеулері

Задания локально в браузере сохраняются так же, как до изменений. API генерирует вопросы, но не сохраняет загруженные материалы. Перед назначением учителю нужно проверить правильные ответы и соответствие учебной программе. Для материалов с диаграммами/иллюстрациями лучше загрузить фото или PDF со страницами целиком.
